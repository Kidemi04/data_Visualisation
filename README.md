# Australian Appliance Energy Website

Live website: https://data-visualisation-indol.vercel.app

## Project overview

This is a small interactive website about television energy consumption in Australia. It was created for COS30045 Data Visualisation Tutorial 01.

## Assignment requirements covered

- Home, Televisions and About Us views
- JavaScript navigation between the three views
- Power logo that returns to Home
- Hover and current-page navigation feedback
- External CSS using colours that match the power logo
- Footer with the year, student name and GenAI acknowledgement
- Placeholder television energy content using the supplied dataset
- Public GitHub repository and Vercel deployment

## Files

- `index.html` contains the three website views.
- `styles/styles.css` contains the layout, colours and responsive styling.
- `js/main.js` controls navigation and updates the year.
- `data/tv_2026_09_08.csv` contains the television dataset.
